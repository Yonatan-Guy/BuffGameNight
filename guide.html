פותחים שיחה חדשה עם Claude

ב־claude.ai או באפליקציה. מעלים את קובץ הצ'אט, מעתיקים את ההוראות האלה ושולחים אותן יחד איתו. ההוראות באנגלית, אבל Claude יענה לכם בשפה שתכתבו בה.


    
צ'אט ארוך? Claude עובר עליו עם קוד, וזה עובד גם על שנים של הודעות. אם הוא אומר שהקובץ גדול מדי, בקשו ממנו להתמקד בשנה האחרונה.

בוחרים את ההודעות

    
Claude מוצא הודעות שמישהו אחר צחק עליהן: "חחחח", 😂, "אני מת", או דירוג כמו "1" ו־"#5". הוא מראה לכם אותן בסבבים של 15, כל אחת עם השיחה שלפניה. אתם עונים מה להשאיר, למשל:

    4, 11 טוב, 15, 16 בינוני. ב־8 תוסיף עוד הקשר
    
טיפים מהמשחק הראשון שלנו: רוב ההודעות "מצחיקות" רק בחצי. שמרו את הטובות באמת. בדיחה שתלויה בתמונה לא תעבוד. ואם משהו אישי מדי, פשוט אל תכניסו אותו.

    
בסוף Claude ישאל אתכם איך לקרוא לכל אחד, מי מכם ייצא את הצ'אט, ואיך לקרוא למשחק. 15 עד 30 שאלות זה ערב טוב.

רוצים לשנות משהו אחר כך? חוזרים לאותה שיחה עם Claude, מבקשים, ומורידים קובץ חדש.

מה קורה עם הצ'אט

    

      
אצל Claudeהצ'אט עובר דרך Claude כדי למצוא את ההודעות. העלו רק צ'אט שאתם והקבוצה בסדר לשתף, ואם יש ספק, תשאלו אותם קודם.

      
במשחקהקובץ נשמר רק בדפדפן שבו פתחתם אותו. האתר לא מעלה אותו לשום שרת.

      
בטלפוניםכל שאלה נשלחת ישר מהטלוויזיה לטלפונים שבחדר, בלי שמות, ונעלמת בסוף המשחק.

    

    
אם אתם שומרים את האתר ב־GitHub, אל תשימו את קובץ ה־JSON או את הצ'אט בתיקייה של האתר. מה שבתיקייה עולה לאינטרנט.

  


  

    
שאלות

    
חייבים להיות באותה רשת וויי־פיי?
לא, החיבור עובר דרך האינטרנט. אבל אם טלפון נתקע על "מתחברים…", חיבור לוויי־פיי של הבית בדרך כלל פותר את זה.

    
מה קורה אם טלפון מתנתק באמצע?
הוא מתחבר מחדש לבד תוך כמה שניות, עם אותו שם ואותו ניקוד. אם סגרו את הדפדפן, נכנסים שוב לאתר ולוחצים "לחזור לחדר".

    
אפשר להוציא מישהו מהחדר?
כן. בלובי יש ✕ ליד כל שם, ובאמצע המשחק יש כפתור "שחקנים" בפינה.

    
אפשר לשחק בלי לשתף את הצ'אט עם Claude?
אפשר לכתוב את הקובץ ביד לפי הפורמט שלמטה, אבל זה הרבה עבודה. החלק של Claude הוא למצוא את ההודעות בין אלפי שורות.

How to make a game from your chat

  
Export your group from WhatsApp, pick the funniest messages together with Claude, and get one file the game reads. About twenty minutes, and you can play it as often as you like.


  

    
_chat.txtThe WhatsApp chat, without media

    →
    
who-sent-that.jsonThe file Claude builds with you

    →
    
4821The room code on the TV

  


  
1

    
Export the chat

    
From any group member’s phone. Choose Without media: photos aren’t needed and the file stays small.

    

      
iPhone
    
        
  1. Open the group and tap its name at the top
    2. 
        
  2. Scroll down: Export Chat
    3. 
        
  3. Without Media
    4. 
        
  4. Save to Files or send it to yourself

        
You get a .zip. Upload it as is, or open it and upload the _chat.txt inside.

      
Android
    
        
  1. Open the group
    2. 
        
  2. ⋮ → More → Export chat
    3. 
        
  3. Without media
    4. 
        
  4. Save it or send it to yourself

        
You get a text file named like WhatsApp Chat with…txt.

    

    
Menu names can differ slightly between WhatsApp versions.

  


  
2

    
Start a new chat with Claude

    
On claude.ai or in the app. Upload the chat file, copy these instructions, and send them with it.

    

    
Long chat? Claude goes through it with code, so years of messages are fine. If it says the file is too big, ask it to focus on the last year.

  


  
3

    
Pick the messages

    
Claude finds messages that someone else laughed at: "hahaha", 😂, "I’m dead", or a rating like "1" or "#5". It shows them in rounds of 15, each with the conversation before it. You reply with what to keep, for example:

    4, 11 good, 15, 16 ok. Add more context to 8
    
Tips from our first game: most messages are only half funny, so keep the really good ones. A joke that needs a photo won’t work. If something is too personal, just leave it out.

    
At the end Claude asks what to call each person, which of you exported the chat, and what to call the game. 15 to 30 questions makes a good evening.

  


  
4

    
Get the file

    
Tell Claude build and it gives you a download called who-sent-that.json. Keep it on the computer you’ll connect to the TV, for example in Downloads.

    
Want changes later? Go back to the same chat with Claude, ask, and download a new file.

  


  
5

    
Play

    
On the computer connected to the TV, open the site → Host a room → drop in the file → Open the room. Everyone scans the code on the screen with their phone and types a name. Nothing to install.

    
Each question shows a piece of the conversation with the names hidden. Everyone picks on their phone who sent the highlighted message. The reveal uncovers the names and the laughs that followed. A fast correct answer is worth up to 1,000 points.

    
To the gameYou can try a sample group first, no file needed.

  


  

    
Where your chat goes

    

      
With ClaudeThe chat goes through Claude so it can find the messages. Only upload a chat you and your group are fine sharing; if in doubt, ask them first.

      
In the gameThe file is saved only in the browser where you opened it. The site never uploads it to a server.

      
On the phonesEach question goes straight from the TV to the phones in the room, without names, and is gone when the game ends.

    

    
If you keep the site on GitHub, don’t put the JSON file or the chat in the site folder. Whatever is in that folder goes online.

  


  

    
Questions

    
Do we need to be on the same Wi-Fi?
No, it connects over the internet. If a phone gets stuck on "Connecting…", switching it to the home Wi-Fi usually fixes it.

    
What if a phone disconnects mid-game?
It reconnects by itself within seconds, with the same name and score. If the browser was closed, open the site again and tap "Back to room".

    
Can I remove someone from the room?
Yes. In the lobby there’s a ✕ next to each name; during the game there’s a "Players" button in the corner.

    
Can we play without sharing the chat with Claude?
You can write the file by hand using the format below, but it’s a lot of work. Claude’s part is finding the messages among thousands of lines.
